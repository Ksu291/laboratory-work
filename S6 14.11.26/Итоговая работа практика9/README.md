# Практика 9 — анализ перевозок

Проект выполняет анализ данных о перевозках за апрель и май.

## Как запустить

1. Установить Python.
2. Открыть папку проекта в VS Code.
3. Установить библиотеку:

```bash
pip install -r requirements.txt
```

4. Запустить программу:

```bash
python run.py
```

## Что делает программа

- загружает таблицы с рейсами и справочниками;
- объединяет рейсы за два месяца;
- добавляет информацию о перевозчиках и клиентах;
- считает показатели и сравнивает план с фактом;
- сохраняет таблицы в `data/processed`;
- сохраняет отчёт в `reports/report.txt`.

## Структура

- `config.py` — настройки;
- `run.py` — запуск всей программы;
- `src/load.py` — загрузка данных;
- `src/prepare.py` — подготовка данных;
- `src/analyze.py` — расчёты;
- `data/raw` — исходные таблицы;
- `data/processed` — результаты;
- `reports` — отчёт.
